### Authoring details

- A split lead uses explicit rows for each phrase so the binder knows where the words change owners. A hyphenated sung token can span rows in its phrase. Keep the whole token in that phrase. The portrait override can replace the parts tuple. A named accent can resolve to a uniquely matching lead part. A part’s authored camera frames the lead phrases laid out through that part so the preceding action can stay in view.
- Write a row override as `{text: 'IN STRIDE', size: 'hero', ink: 'reply'}` and a word override as `words: {BITE: {ink: 'hit'}}`. Stable token IDs disambiguate repeats. Set the storyboard palette with `look.ink` and supply the court ground as a hex colour. The preset night ground takes `look.palette.ground`.
- Interlude rows use `echo('RING')` or `{text: echo('YEAR 24'), size: 'hero'}`. Multiword echoes expose individual word landmarks, so `word('year-24', 'YEAR')` and `word('title', 'ONE')` resolve. Use a frame gap or numeric clock on the row cascade. Place an interlude before its vocal successor in the scene’s `lines` array. A later interlude with no camera call holds the current framing. A named accent on the interlude starts at its landing. Set explicit times and valid landmark sources for each selected edit.

### Motion and timing

- Typed `rise({dir})` names the direction of motion. A rightward word starts with negative `dx`. Its displacement starts at `min(2 × extent, max(extent, projected source distance)) + gap`. The **200 px** limit applies to the optional gap. The default length is **8 frames**. Cubic ease-out spends most travel while the opacity is low. At **0.5 opacity**, about **42%** of the initial displacement remains. A short connective moves a much smaller distance than a hero word. In the tuned shot, FREE starts **437.92 screen px** from its rest position at opacity 0 and has **184.75 screen px** left to travel at opacity 0.5, measured from the effect displacement at that frame’s zoom. The visual impression of travel remains a browser check.
- The verse gap claim holds for consecutive onsets in the legacy song map. **185 of 198 gaps** are shorter than **0.5 s** across storyboard lines 4–15 and 20–31. The reading window uses the accepted first readable frame and the mapped vocal end. A drawn entrance can still spoil another token’s protected read even if its resting box clears it. YEAR 1’s storyboard stamp failed that test at frame **152** in the held-RING fixture. Changing YEAR 1 to a quick type-on passed without shortening RING!.
- `matchCut` does lift and fade unmatched incoming glyphs on their word timing in vocal cards. It leaves unmatched outgoing glyphs to the fate. `slotRoll` replaces the outgoing ink in its actual source block. On line 25, only the source block `v2.5.p2` rolls. The compiler retires sibling blocks, including KCP and BRON, via `stay()` if the card supplies no other fate. Recheck the intended persistence in a wide shot.
- `follow({fill})` frames its resolved target and emits a move before the hold. It cannot guarantee the storyboard’s wider multi-line composition, an exact repeated frame, or a screen-edge-relative placement just from `fill`. A source required by an entrance still has to be visible. `type` is source-independent, so an earlier-authored but later-sung anchor can position the count. A true forward card reference is still a compile error.
- `turnIn` requires `edge(...)` as its source in this compiler, even with an explicit pivot. The standing stack qualifies. The row and word anchors combined with `turnIn` in lines 8, 9, 11 and 26 and the hook 2 override do not. A turned resting block does not rotate its independently placed ordinary `below` or `right` parts. The author should check the camera angle on those combinations.
- `zoomLadder` only pushes in. Its definition accepts explicit repeat frames. The compiler uses the default spacing, independently of the KING! onsets. An explicit interlude camera uses the card’s start. The standalone `last.push` camera-only card, custom two-beat push schedule, and a scheduled final fade before the scene end are outside this echo-card contract. Scene `exit` begins at the scene boundary. Plan the cuts and holds with those timings in mind.
- `preset` permits earlier readability and clamps the protected start. It does not assign an earlier entrance frame, duplicate a token, or decouple PHILLY’s swell from the mapped onset. `beatPunch` only scales and runs once per authored call, aligned to the selected vocal onset or interlude landing. The repeated and separately timed pulses, reply-word punches, cross-card THREE! punch and colour change, and literal `camera: none` shorthand are unsupported. The shared THREE! can be omitted from the crowd card, but omission gives it no independent sync interval.

### Legacy adapter

Node resolved all **9 distinct storyboard names** among **49 registered verbs**. The storyboard ledger lists **10 entrance uses** across its six entrance names. The three other names are used for exits. The typed `cascade` API accepts unit calls. Forcing a legacy call through untyped JavaScript still produces no stagger because the compiler lowers the legacy call directly. Each registered definition determines which runs it animates.

| Verb | What the registered code actually does |
|---|---|
| `drawer` | Requires a host word or `params.rect`. Defaults to the host’s bottom edge. Use `{edge: 'right'}` for the sideways pull. It animates each affected word against its own sung onset, without a wrapper. |
| `converge` | Brings copies of each affected word together with a default **14 px** offset and opacity ramp. It does not send DRAWS and TWO in as two distinct opposing trajectories. The board’s `arrival-fade` rule flags the small displacement in the fixture. |
| `spread` | Tracks the cue’s first word apart while it is visible. WHOLE spreads in WHOLE FLOOR, and GIVE spreads in GIVE HIM SPACE?. This is a tracking cue, with no hidden-to-visible entrance. |
| `rush` | Approaches a vanishing-point target, holds, then swells and fades. It can address several runs on the same cue. Its lead window is up to **90 frames**. Sample the actual onset and hold, since the generic legacy compiler schedule does not model that internal approach and exit. |
| `swell` | Grows the first run. The plain-cue variant can push neighbours in other blocks. The emerged variant reads the source word, and can replace it. Treat a ring used as the source as a continuity risk. |
| `shove` | Bare `legacy('shove')` does not select the push variant or resolve a target from the word landmark. The plain variant needs `params.target` and optionally `to`. The emergence variant needs `mode: 'push'` on the generic adapter and a source or explicit target. The fallback using the line’s `old` fate also affects its parts, including TACKO FALL. |
| `vanish` | Handles multiple runs by fading glyphs successively, with **2 frames** between letter starts by default. |
| `fling` | Throws each affected run along a parabola. The default fade finishes after **1.4 s**. |
| `turn` | Registered and accepted as a scene exit. The scene exit uses the board’s turn path. `turnSwap` is a mode of `turn`, with no separate registry entry. |

`slideFrom` **is registered** in the loop in `engine/emergence/slide.ts`. It requires a real anchor or an edge. The storyboard’s reason for dropping it is incorrect. `slideFrom` is available through the existing legacy adapter.
